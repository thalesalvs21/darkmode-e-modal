# Dark mode e modal

Exercício de JavaScript com duas funcionalidades bem comuns em sites:

- **Tema escuro** — um botão alterna a classe `mododark` no `body`, trocando as cores da página inteira de uma vez só
- **Modal** — clicar em um card abre uma janela sobreposta, usando o elemento `<dialog>` do HTML

## Tecnologias

- HTML
- CSS
- JavaScript

## Estrutura

```
index.html
style.css
script.js    # alterna o tema claro/escuro
modal.js     # abre o modal ao clicar nos cards
```

## Como rodar

Abra o `index.html` no navegador.
